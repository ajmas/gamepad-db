# GamePad DB

This project looks to create a database of game pads that have been
recognised to work with the browser based GamePad API, though if
there is interest to extend this to other usage contexts, then we
are open to this.

This project is a community run effort and does not look to make
money from its work.

Any feedback or suggestions are appreciated

## The Data Structure

The folder structure is presened in REST-like form, with `controllers/index.json`
listing the known controllers and then the other files in the folder correspond to
the short name, with the data in JSON format.
